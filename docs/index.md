# Privacy Policy — MORSE

Last updated: 2026-11-06

MORSE does **not** collect, transmit, or share any personal data.

- All data the app stores (username, game scores) is kept **locally on
  your device** and never leaves it.
- The app uses **no analytics, no ads, no tracking, and no account
  system**.
- The only network request the app can make is opening the project's
  public GitHub issues page in your browser, and only if you tap the
  feedback button yourself.

Uninstalling the app removes all locally stored data.

Contact: open an issue at
<https://github.com/samuele-brusegan/morse-flutter/issues>
